# 苍爪熊：怪物设定与八方向绘图提示词

日期：2026-10-22。状态：美术提案，尚未生成图片或替换游戏资源。

用户要求：参考《怪物猎人》的青熊兽并简约化；两只爪子就是武器；需要正面、背面、左右侧面及四个斜角，共八方向。

## 1. 建议的角色设定

暂名“苍爪熊”，名字可以更改。参考青熊兽的蓝色熊型体态、强壮前肢与利爪。原作参考：[Monster Hunter Now 官方介绍](https://monsterhunternow.com/en/monsters/arzuros)。

下面的具体比例、配色和爪数是为本游戏提出的设计选择，并非对原作设定的复述：

- 风格：简约 2D 卡通手绘，干净粗轮廓，大色块，两档阴影，非像素风。
- 气质：沉重、倔强、有威胁感，带一点憨劲，避免幼崽或玩偶比例。
- 体态：约三头身，双足站立，宽肩、厚背、圆腹、短粗腿，头微微前伸。
- 头部：短熊吻、两只小圆耳、两只琥珀色小眼睛、低压眉线。
- 身体：主色深青蓝，口鼻与腹部米黄色；背部仅少量块状毛簇。
- 武器：左右各一只特别粗大的前臂和爪掌；每只爪有三枚象牙色长爪，爪尖弯曲、轮廓分明。
- 简化细节：每个前臂外侧用三块大号青灰色甲片表现硬壳，不画密集鳞片和细毛。
- 基础姿态：双脚稳定落地，身体正直略前倾，双臂稍外展、肘部略弯，爪尖斜向下。正面下两臂与躯干之间有清楚间隙。
- 轮廓重点：缩小观看时仍能读出“头、圆腹、两只大爪”。尖爪的浅色帮助玩家看清攻击方向。

正面战斗先使用正面资源；八方向用于设定一致性和后续扩展，暂不意味着要实现八方向移动。

## 2. 第一张正面设定图：可直接复制

> 为一款 2D 动作游戏绘制单个熊型 Boss 的正面角色设定图。以《怪物猎人》青熊兽的厚重熊型轮廓、强壮前肢和利爪为外形参考，设计一个经过简约化处理的“苍爪熊”。约三头身，双足站立，宽肩厚背、圆腹、短粗腿、小圆耳、短熊吻、琥珀色小眼睛，表情倔强而有威胁感。身体覆盖深青蓝色皮毛，口鼻和腹部为米黄色，毛发概括成少量大块形状。左右前臂明显粗壮，各有三块青灰色大甲片；每只爪掌长有三枚醒目的象牙色弯曲长爪，两只爪就是它的全部武器。双臂稍微外展，肘部自然弯曲，爪尖斜向下，与躯干留出清楚间隙，便于以后拆分手臂做动画。干净一致的深色轮廓线、平涂大色块、两档阴影，简约卡通手绘游戏素材，保持成年猛兽的重量感。固定正面平视镜头，近似正交投影，全身居中，双脚完整落地，头顶和爪尖都在画布内，四周留白，浅灰纯色背景，均匀柔光。画面只包含这个角色，没有文字、水印、道具、场景、刀光或运动模糊。不要增加持握武器、额外手臂、翅膀或角，不要密集鳞片、写实细毛和复杂金属装备。

第一张用纯色背景方便审视轮廓。正式游戏贴图再要求真正的透明背景 PNG，不把棋盘格画进图片。

## 3. 八方向生成方法

先确认第一张正面设计，再在后续生成中附上它作为角色参考。尽量以同一张已确认参考图生成其他方向，减少逐图变形积累。仅重复相同文字不能保证八张完全一致。

通用提示词：

> 根据附带的已确认角色参考图，绘制同一只苍爪熊的【指定视角】全身图。严格保持同一个角色的头身比例、头部大小、肩宽、前臂长度、三枚爪子的设计、甲片数量和位置、皮毛块面、颜色和轮廓线风格。保持同一中立站姿和表情，仅改变角色相对于镜头的水平朝向。镜头高度、近似正交投影、画布尺寸、角色站立高度、脚底基线和光照方向固定，所有视图共用相同脚底中心对齐点。允许遮挡自然发生，侧面不强行露出被身体挡住的另一只眼睛或另一条手臂；不能为露出爪子增加肢体。全身完整，留出爪尖与脚底余量，真正透明背景，无文字、无方向箭头、无背景场景、无地面投影、无动作特效。

将【指定视角】替换为下表描述。“左、右”统一指画面方向，避免把角色解剖学左右与观看方向混为一谈。

不要让镜头跟随角色转动，八张都是同一固定镜头下不同朝向的角色，也不是俯视或等距视角。

## 4. 一次生成八方向设定表：用于选型

> 根据附带的苍爪熊正面参考图，制作同一角色的八方向转面设定表，4 列 × 2 行，格子等大、角色互不重叠。从左到右、从上到下依次为：正面、前右 45 度、朝画面右的侧面、后右 45 度、背面、后左 45 度、朝画面左的侧面、前左 45 度。八格是同一只怪物的同一中立站姿，仅改变水平朝向，统一画布内的站立高度、脚底基线、头身比例、配色、光照与画风。深青蓝皮毛、米黄色腹部和口鼻、左右各三块前臂甲片、每只爪三枚象牙色长爪的设计在各视图保持一致，遮挡遵循实际方向。正交平视全身，所有耳朵、爪尖和脚都完整，浅灰纯色背景，格间留足空隙，不加文字、标注、水印或攻击特效。

这张表用来确认造型，不直接当作已对齐、可动画的游戏图集。正式导入时分别检查每张的透明边缘、尺寸、脚底对齐点和爪子数量；生成结果可能仍需要校正。

## 5. 两只爪作为武器，如何准备动画素材

八方向转面只是朝向，不等于攻击动画。当前正面战斗最先需要的是正面基础图与独立手臂，之后再制作左右横扫、下砸、受击和易伤姿势。

建议先拆最少三组：躯干/头/腿的主体、左前臂连爪、右前臂连爪。若动作需要更大的肘部弯曲，再细分上臂与前臂。拆分层之间保留被遮挡区域，避免转动后露出透明洞。

拆件提示词：

> 根据已经确认的苍爪熊正面图制作动画拆件素材。保持原角色比例、线条、配色和光照。分别提供：完整身体底图，怪物自身左侧的前臂与爪，怪物自身右侧的前臂与爪。两只爪各保留三枚象牙色爪刃。身体底图补全原本被手臂遮住的躯干；每个前臂在肘部连接端补足自然的覆盖区域，便于转动。拆件姿态与原正面图一致，不附加武器或刀光。每个部件单独透明背景、完整不裁切，保持相同像素比例，不把每个零件各自放大到填满画布。

注意：正面时“怪物自身左臂”出现在画面右侧。当前 Godot 肩部挂点按屏幕左右命名，导入时必须在美术接入记录里写清映射，不能只凭文件名猜测。

Boss 现有独立矩形武器目前仅是原型表现。采用双爪后，需让左右手臂各有自己的爪尖/攻击起点，攻击轨迹跟随对应爪子；此次仅讨论提示词，不改变现有战斗代码。

## 6. 首轮选图检查

- 正面一眼能认出熊型怪物，两只大爪比身体小纹理更抢眼。
- 头、身体和爪的轮廓缩小到游戏显示尺寸后仍清楚。
- 双方侧面没有额外肢体，背面没有长出第二张脸。
- 视图间头身比、腹部色块、甲片和爪数保持一致，隐藏部件允许自然遮挡。
- 镜头没有在某些方向变成俯视、透视夸张或不同远近。
- 八方向保持中立姿态；攻击、受击与易伤另外制作。

下一步优先确定正面基准图的画风和轮廓，再生成其余七个方向与正面手臂拆件。
