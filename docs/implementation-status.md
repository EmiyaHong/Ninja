- Boss 等待、蓄力和收招期间均可被普通命中：默认生命-10、架势-6。**不再使用蓄力期被防住而零生命伤害规则。** 普通命中不自动中断攻击，架势归零才中断。
- 弹反仍是方向+时机，没有双刀空间相交要求；0.9秒预警，最后0.20秒窗口内反向划，方向容差±35°。窗口内新鲜片段优先判弹反，同笔不叠普通伤害；三种攻击默认固定顺序，可勾选随机。
- 架势从100降到0，进入默认2秒、2倍生命伤害的易伤。触发归零的一击使用命中前倍率，后续实际命中才享受易伤。期间架势保持0、不重复触发、不刷新倒计时；结束恢复满架势。输入发生在易伤到期后、该帧更新前时也会先恢复正常倍率。Boss死亡优先于同时归零的架势。
- UI显示生命/架势当前与最大值、本次实际生命损失/架势损失、易伤倍率和剩余时间；暂停时仍能看易伤数值。
- 新增**木桩测试模式**：Boss不主动攻击，但可以受伤、削架势、易伤和重置。自由练刀模式继续完全不结算伤害。
- 美术接口：角色头/身体贴图、整体视觉场景、可选左右肩/手臂挂点；武器贴图/视觉场景、明确刀尖Marker和源图刀尖偏移。可选手臂缺失也能正常运行。
- 刀迹改为独立Line2D，Inspector可实际指定材质/ShaderMaterial、纹理、宽度和颜色。显示与输入、伤害及弹反判定分离。

上述数值均是可调试玩默认值，尚不代表用户确认的最终平衡。

## 新手如何直接测试

1. Godot打开本目录 `project.godot`，按 **F5**。
2. 按 **4** 进入木桩：持续按住左键，从Boss身体两侧来回划，不用松开。框线表示简单受击区；空处挥刀不扣血。每次有效命中按当前配置扣血和削架势，初始默认10/6。
3. 默认连续17次命中清空架势，第17击仍伤害10；随后2秒内的命中伤害20。易伤期间架势保持0，等待结束恢复100。顶部和底部都显示本次变化。
4. 按 **2** 自由练刀：画圆弧、S形、折返，观察白点（实际刀尖）和刀身，Boss不掉血。
5. 按 **3** 下劈训练：提示变金色时向上划。按 **1** 战斗：Boss左→右时向左划，右→左时向右划，上→下时向上划。可一直按住左键，在不同招式之间改变划动方向；刚命中后的最短出刀间隔内仍不能弹反。
6. **R** 重置当前模式及全部数值；**Esc** 暂停/继续。失焦自动暂停，恢复后须重新按下左键。

可独立运行：打开 `scenes/training_dummy.tscn` 或 `scenes/gesture_lab.tscn` 后按 **F6**。F5始终运行战斗。

## 已知限制与下一步

- 连续刀刃检测采用相邻样本刀尖/刀根形成的保守扫掠凸包与简单矩形受击区，属于易理解的原型判定。极端急转时可能比真实旋转刀刃的面积宽松；没有像素级或物理刀刃碰撞。若用户观察到边缘误命中，可再细化旋转扫掠。
- 急转时刀身直接跟随切线；超长按住轨迹尚未做点数优化。松开即时回到悬浮待机，没有手臂约束或持刀动画。
- 未制作最终Shader、正式美术、音效、全局打击停顿、移动、闪避、成长和Windows发布包。
- 未做真人连续10局、不同显示器尺寸和三种真实帧率的手感验收。自动检查和输入注入不能替代用户手感反馈。
- 下一步先用木桩观察每次生命/架势变化和易伤；再看蓄力期普通攻击是否容易抢占本笔弹反资格。根据反馈调伤害、输入阈值与易伤时长，之后补更清晰动作和声音。
