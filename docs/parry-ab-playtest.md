# 木桩弹反 A/B 试玩

状态：2026-10-22 已实现并做规则与MCP输入验证，**待用户真人对比手感**。这是实验，没有替用户选定正式规则。正式战斗仍使用原来的严格反向逻辑和用户保存的参数。

## 如何启动

1. Godot打开本项目，按 **F5**。
2. 按 **4** 进入木桩，顶部第二排会出现中文选项。
3. 按 **G** 或点“弹反训练”；按 **A** 选择双向接招，按 **B** 选择严格反向。
4. **C** 切换“同向三连 →→→ / 交替三连 →←→”。看金色窗口和“玩家可弹”提示挥动。
5. **R** 重开当前训练；**Esc** 暂停/继续。**T** 回到静止伤害木桩。

也可打开 `scenes/parry_ab_lab.tscn` 后按 **F6**，直接进入实验。原入口仍保留：1正式战斗、2自由练刀、3旧下劈训练、4木桩。

切换规则、连段或重开都会清掉旧手势、旧三刀、统计与计时，需要重新按住左键。**一组内可以一直按住，不需要每刀松开。** 没有鼠标捕获、自动回中或自动漂移回刀；回位由你自己完成。

## 两种规则怎样比较

| 规则 | Boss从左向右来刀时，玩家可用方向 |
| --- | --- |
| A 双向接招 | 向左或向右，方向轴相同即可 |
| B 严格反向 | 只能向左，即来刀的反方向 |

先选“同向三连”，Boss固定连续三次从左向右：

- **A**：在三个金色窗口依次向左、向右、向左，试自然往返接刀。
- **B同样动作**：左、右、左，预期第2刀因方向相同而失败；第1和第3刀成功。
- **B加回位**：向左弹 → 窗口外向右回位 → 向左弹 → 向右回位 → 向左弹，预期三刀成功。
- 再选“交替三连”：Boss来刀为右、左、右。B用左、右、左即可自然往返全部接住。

HUD分别写明 **Boss来刀** 与 **玩家可弹**，不要把两种箭头混淆。一次清晰有效挥动若在窗口内方向不符合本模式，该刀立即记失败；这不会改变后续刀的时刻。没在窗口内挥动则在命中时记“错过窗口”。

## 共同时间表与参数

两种模式读取同一份独立训练配置：`data/parry_training.tres`，每个训练实例深复制到内存。**不会继承或覆盖** `data/combat_tuning.tres` 的1秒窗口、90度容差或其他用户调参。以下是本次实验起点，不是最终平衡：

| 项目 | 当前值 | Inspector属性 |
| --- | --- | --- |
| 弹反窗口 | 命中前0.20秒，含命中时刻 | Parry Window |
| 方向容差 | 允许方向±35度 | Direction Tolerance Degrees |
| 局部观测时间 | 0.08秒 | Local Window |
| 最小局部位移 | 视口短边2%，768高时约15.36逻辑像素 | Minimum Distance Ratio |
| 最低局部速度 | 180逻辑像素/秒 | Minimum Speed |
| 第1刀命中 | 重开后1.20秒 | First Impact Delay |
| 连刀间隔 | 固定1秒，第2/3刀在2.20/3.20秒 | Impact Interval |
| 可见蓄力 | 0.8秒 | Windup |
| 组间休息 | 第3刀命中后2秒，下一组第1刀在6.40秒 | Group Rest |
| 停顿后重新挥动 | 至少0.12秒没有明确移动 | Pause To Rearm |
| 折返重新取得资格 | 相对上段方向至少转60度，转折位移短边1% | Turn Angle Degrees / Turn Distance Ratio |

窗口、方向、速度、距离对A/B完全相同。提前成功、方向失败或漏接都不移动下一刀的绝对时刻。训练只记刀次与整组成功/失败，不扣双方生命、架势，不触发破防/死亡，也不触发普通攻击或正式战斗冷却。

## 什么算新的一次挥动

刀尖和曲线沿用现有输入与刀光。判定只看窗口内的新鲜局部样本，不用整条曲线首尾向量。

- 可以**清晰折返**，或**停一下再启动**，取得下一刀的挥动资格。
- 一段持续直线拖动最多接住一刀；不会因为跨过三个窗口就自动连弹。
- 回位在窗口外不会算普通伤害，也不会消耗下刀的弹反冷却。
- 按下定位、静止、细小抖动和窗口外已结束的旧挥动均不能弹反。
- 鼠标事件采样有间隔，应在金色窗口内留出一小段清晰移动。高频采样下短边2%的局部距离即可；不需要大幅甩到屏幕边缘。

### 待用户真人试玩

请优先反馈：A往返是否顺手；B回位是否紧张或费空间；交替连段是否更适合B；金色窗口、箭头和失败提示是否能及时看懂；短距离手势是否容易触发。此轮没有自动回刀、施压反应、架势恢复新规则或忍杀等额外玩法。

已知限制：新挥动资格是简单的转角/位移/停顿阈值，缓慢的大圆弧可能被分成新段；极短折返会被当作抖动而忽略。当前试玩连段仅提供水平来刀；匹配函数的竖直轴已做自动检查，未添加额外下劈组。训练不是正式数值平衡工具，数值测试请按T切回静止木桩。

## 代码入口

- `scripts/parry_trainer.gd`：固定三刀时间表、A/B匹配、手势资格、逐刀与整组结果。
- `scripts/parry_training_tuning.gd` + `data/parry_training.tres`：独立可调实验参数。
- `scripts/battle_controller.gd`：木桩菜单、快捷键、训练HUD与武器表现；训练分支隔离正式结算。
- `scripts/gesture_input.gd`：仅补充运动片段起点时间，保留现有采样与刀光接口。
- `scenes/parry_ab_lab.tscn`、`tests/parry_ab_tests.tscn`：直接试玩与规则检查入口。
