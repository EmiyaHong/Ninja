# 方向手势对战实验（2026-10-23）

## 交互故障修复补记

用户反馈“完全没法玩，按1无法回原模式”后，原版正常循环事件注入发现：纯 `physical_keycode` 输入和小键盘数字不受原 `event.keycode` 匹配支持。修复为全局 `_input` 优先物理键、逻辑键兜底、小键盘归一，识别后标记事件已处理；GUI获得焦点不再决定全局命令能否到达。原版主键切换及点击5后主键1在本次环境已能工作，不能把未复现的整个现场问题归因于GUI焦点。

`tests/interaction_tests.gd` 可用 `Godot --path 项目目录 --script res://tests/interaction_tests.gd` 运行。它在正常process/真实时钟下通过事件分发点击实际按钮、注入按键和鼠标，不调用模式/重置函数。默认D3D12 Forward+与OpenGL Compatibility分别19项0失败，包含1→5→1、按钮焦点、物理数字键、小键盘、R/Esc、鼠标绝对刀尖恢复、空白处指令斩击、连续三次弹反、自然败北及恢复原参数。原规则回归265项仍通过。

现场证据：`docs/screenshots/interaction-directional-real-clock.png`、`interaction-original-restored.png`；新日志在忽略的 `.mcp-tools/interaction-*.log`。未修改原combat_tuning、美术或刀光；原刀光3项过期失败仍在。此轮消除了上一轮受控时钟/停process的验证缺口，但仍是Godot事件注入，非用户键盘/IME/真实OS切窗验收。未找到遗留测试进程；实际F5配置和编辑器当前场景均为battle。用户现场是否完全恢复仍需反馈。

状态：已实现，可试玩；未经过用户手感确认，未替代原控刀，也未决定 A/B 最终规则。

## 操作

- F5 启动，按 **5** 或点击“5 方向手势”；按 **1** 回原刀尖直控战斗。2/3/4、T/G、A/B/C 原入口保留。
- 在视口空白区域按住左键短划，自动对准唯一的熊；无需划过熊。右、左、上、斜向均按连续方向向量驱动飞剑。
- 可一直按住。清楚转向至少 65°、累计转向位移至少 8px，或停顿至少 0.12 秒再划，可重新出刀。直线长拖只用一刀；不足 0.5px 的事件不刷新停顿计时。窗口内新鲜严格反向挥动可取消普攻弹反。
- R 重开，Esc 暂停/恢复。失焦自动暂停。暂停、切换、重开、胜败清理动作；恢复后重新按住。松开不撤销已经发出的飞剑。

## 路径与结算

自动锁定熊受击框中心，刀尖起点为中心沿手势反方向 220px、终点为正方向 220px，0.26 秒线性飞行。整个刀身和现有刀光跟随这段真实位移，方向不离散成四向动画。起点定位和回到玩家待机位显式清空刀迹，不检测伤害，不绘制跨屏转场轨迹。路径保证经过目标，是单目标指令斩击，不是空间瞄准或自由曲线。

普通攻击复用现有刀刃扫掠命中检测，实际经过受击框时才结算一次。动作期间普通新手势会消费但不缓存，需下一次新挥动再出刀；因此快速乱摇不是无限攻击。反向弹反不受普通出刀冷却/当前动作阻塞，输入合格时立即结算弹反并替换旧飞行动作，新动作为防御斩击，不叠加普通伤害；被取消旧动作没有延后伤害事件。已经发生的普通命中不会倒扣。

手势需在弹反窗口内重新起笔/转向，旧手势不能跨窗口自动变成弹反。熊时间线、生命/架势、破防倍率、胜败和重开沿用原战斗结算。

## 独立参数与比较边界

`data/directional_combat.tres` 使用 CombatTuning 默认值：玩家100、熊300/架势100、伤害10/架势6、弹反削架势30、熊伤害20、易伤2秒×2、窗口0.20秒、方向容差35°、短边2%且速度≥180px/s、观测0.08秒。HUD显示关键参数。专用动作和重启阈值在 `scripts/directional_combat.gd` 常量及判断中，未与原0.18秒普通攻击冷却共用。

原 `data/combat_tuning.tres` 完全保留，可能含玩家10000、窗口1秒、容差90°等用户调试值；切回1恢复原资源。两模式默认难度不同，不能把难度变化说成控制优势。对比手感前需另行统一参数。

## 本次验证及限制

独立 Godot 4.7.2 headless：方向模式34项0失败，原战斗101项0失败，A/B41项0失败，几何熊89项0失败。方向检查覆盖远处短划、四种方向真实位移、非即时伤害/单击、回位、直拖限制、持续折返、弹反取消与旧伤害不复现、破防倍率、双方胜败、暂停和原参数恢复。

另用有画面的 Godot OpenGL Compatibility 进程，按帧注入 Input.parse_input_event 鼠标事件：在(100,550)按下，向右上短划至(130,520)，得到飞剑方向(0.707107,-0.707107)，实际命中后熊290/架势94、结算1。截图 `docs/screenshots/directional-gesture-flight.png` 与 `directional-gesture-hit.png` 已查看，能见斜向剑、发光刀迹、熊、入口与中文说明。验证采用受控时钟及手动推进动作以抓取瞬间，不等同真人持续完整对打、真实多帧率体验或默认 D3D12 渲染验收。

初次截图注入全部发生同一帧，未产生有效速度；改成逐帧事件后生效。首次HUD中百分号格式错误已修正，最终日志无该错误。原刀光16项中3项轨迹过期失败为已知问题，本轮未改刀光脚本/着色器，不能宣称其已修复。转场会主动清理刀迹避免该问题造成跨屏残迹。

当前无连招缓存、移动、空间目标选择或额外美术。清理失焦沿用原自动暂停路径，未做真实操作系统切窗注入；连续折返的真人舒适度及弹反动作表现仍需试玩反馈。
