## 2. 如何运行与操作

1. 使用 **Godot 4.7.2** 打开本项目根目录 `project.godot`，按 **`F5`** 运行主场景 `res://scenes/battle.tscn`。
2. **常用操作与快捷键**：
   - **`1` 键（1 战斗 · 当前主线）**：`WASD` 或方向键控制角色八向移动；**按住鼠标左键不松开**持续划动控制飞剑（无需每次松开左键）。
     - **普通攻击**：走近使 Boss 躯干受击框进入你的 `260px` 飞剑圈（圈与框变亮青色），划过 Boss 身体造成生命与架势伤害。
     - **弹反（B 严格反向）**：当 Boss 蓄力预警进入金色窗口，且 **Boss 挥击爪的判定框在你的飞剑圈内** 时，**逆着 Boss 攻击方向**快速划动鼠标即可弹反，大幅削减 Boss 架势并打断攻击。
     - **走位闪避**：趁 Boss 蓄力时用 `WASD` 走出其爪击覆盖范围，可在落爪时刻无伤躲开（但出圈后也无法弹反或攻击）。
   - **`2` 键（自由练刀）**：Boss 不攻击，自由测试圆弧、S 形、折返刀路。
   - **`3` 键（下劈训练）**：固定 Boss 下砸招式，练习向上挑弹反。
   - **`4` 键（木桩测试）**：按 `T` 测静止木桩伤害，按 `G` 进入弹反 A/B 对照实验室（`A`/`B` 切换规则，`C` 切换同向/交替三连）。
   - **`5` 键（方向手势实验）**：任意空白处短划给出方向向量，飞剑自动向熊执行短斩。
   - **`R` 键**：立即重开本局；**`Esc` 键**：暂停 / 继续。

## 3. 近期我们干了什么、进行到哪里、下一步干什么

### 最近完成的工作（2026-10-24 · D016–D018）
- **D016**：在 1 号模式做出 `WASD` 角色移动、飞剑 `260px` 圆内范围（圈内跟随鼠标、圈外贴边）、3×3 扩大网格地图与 `Camera2D` 跟随，手势采样保持屏幕坐标以防走路污染挥刀判定。
- **D017**：将飞剑圆升级为**严格最大可攻击判定范围**（`swept_hits_in_circle`），裁剪圈外延伸刀身防止越界蹭伤，并加入受击框与飞剑圈进圈变亮的高亮反馈。
- **D018**：
  - 给弹反加上**双爪距离限制**（以几何熊左右双爪 `boss_claw_hurtboxes` 为判定框，进飞剑圈才能弹反）；
  - 加入 **Boss 待机追击 AI** 与 **玩家受击框（`player_hurtbox`）走位闪避判定**；
  - 正式确认弹反采用 **B 严格反向**；
  - 在 [`docs/design-journal.md`](docs/design-journal.md) D018 绘制了完整的**战斗设计演进思维导图（Mind Map）**。

### 下一步要干什么（待办路线）
1. **真人试玩验收（当前最优先）**：运行 1 号模式，实测 `WASD` 移动速度（`320`）、飞剑半径（`260`）、Boss 追击速度（`150`）与双爪弹反距离的手感是否舒适。
