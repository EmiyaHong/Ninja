# 角色拆件制作手册（剪纸/骨骼动画用）

> **给下一个接手的 AI**：本手册是几何熊正面拆件（`geometric/geobear/parts/front/`）两轮实战踩坑后的固化流程。
> v1 位图抠图被用户否掉（边缘锯齿、碎点、串件），v2 矢量重绘通过验收。**照 v2 做，不要走 v1 老路。**
> 相关脚本：`_tools/_split_geobear_front_v2.py`（现行）、`_tools/_clean_flat.py`（母图清洗）。
> 废弃对照：`geometric/geobear/parts/front_v1_draft/`（勿用）。

---

## 1. 适用场景与输入要求

适用：几何扁平风角色（严格色板、粗描边、平涂无阴影）拆成可关节旋转的部件。
输入母图要求：

- **真透明 RGBA**，画布方正（几何熊正面 1254×1254），角色居中完整；
- **严格有限色板**（几何熊 6 色，见根 README §4.5）——若母图是 AI 生成原图（上万种颜色、JPEG 噪点），**先过 `_clean_flat.py`**：边缘洪泛去背 → alpha 腐蚀 1px 去毛边 → **固定色板最近色映射**。
- ⚠️ **永远不要用自适应量化**（median-cut N 色）修毛边——会把灰甲片、琥珀眼这类小面积色合并丢色。

## 2. 总流程

```
清洗后的母图
  → 逐色连通域分析（scipy.ndimage.label）
  → 按「预期包围盒签名」选定每个部位的连通域
  → 轮廓拟合（凸包 + RDP 简化 → 顶点表）
  → 4 倍超采样重绘部件轮廓（填充 + 统一粗描边）→ 降采样回 1x（边缘 AA）
  → 内部细节贴回原图（脸/护甲/腹块/爪根）
  → 隐藏关节补画（圆/椭圆平涂，无描边）
  → 10 件 PNG（同画布、原位）+ pivots.json
  → 三张验收图（拼回对比 / 分件展示 / 关节活动检查）
```

## 3. 连通域选择的坑（最重要）

**不要**用「与提示矩形相交」选连通域（`comps_in` 写法）——相邻部件会互相误并：
上臂底部伸进前臂提示框 → 上臂被并进前臂，画出来变成整根大板砖；头和躯干在颈部相接 → 头吞掉躯干。

**正确**：`comp_by_bbox(mask, expected_bbox)`——先全图 `ndimage.label`，再选包围盒与预期最匹配的域。预期包围盒从首次连通域分析报告里抄下来作为常量。

## 4. 轮廓绘制规则

| 规则 | 原因 |
| --- | --- |
| 轮廓 = 连通域（含描边环）的凸包 + RDP（ε=5~8） | 忠实还原原始几何形 |
| 4 倍超采样画多边形 → LANCZOS 降回 | 边缘光滑齐平（用户核心诉求） |
| 描边宽 13px、色 `#06070B`，所有部件统一 | 与原图一致；同色描边相接处叠合天然不可见，不必焦虑"双描边" |
| **外轮廓描边一律程序化重绘，不贴原图描边** | 两条描边错开几像素就是碎线/毛边（v2.0 的教训） |
| 内部细节才贴原图：护甲板、腹部色块、五官、爪根 | 保持原作风味 |
| 躯干用**程序化重建表面**（实测逐行轮廓 + 腹块 + 边带描边），不要"抠原图+覆盖擦除" | 擦除会误伤肚皮角（腿痕和肚皮同色区相邻），重建永远干净 |
| 逐行测轮廓时必须先排除手臂/前臂/爪区域并**膨胀 8px** | 否则前臂边缘毛刺污染躯干轮廓测量 |

## 5. 关节补画规则（隐藏区域）

- 补画一律用**圆形/椭圆**平涂青蓝、**无描边**——矩形补画旋转后露直角碎片（v1 教训）。
- 补画量：关节球半径略大于连接处宽度的一半，保证旋转 90° 仍盖住接缝；宁大勿小（大了被邻件盖住，小了露洞）。
- 各关节补画位置（几何熊正面实测）：
  - 颈：头下椭圆 (627,392) rx88 ry45；躯干颈部同区填实；
  - 肩：上臂顶部圆 (300,420)/(954,420) r≈58；
  - 肘：前臂顶部椭圆 (270,560)/(984,560) rx50 ry30；
  - 髋：腿顶椭圆 (465,838)/(789,838) rx60 ry24；
  - 腕：不用垫片，见 §6 爪部特例。
- 补画在部件单看时会露出小圆包，**拼装后被邻件盖住**——属预期，README 里要注明。

## 6. 部位特例

- **爪部（用户明确要求）**：三角爪**只描两侧边，爪根（顶部）不封口**，让爪子从掌部自然长出；手掌 = 前臂底尖多边形，**顶部切边不描线**（否则腕部多一条横线）。用 `draw_poly_open(skip_edge=...)` 按边跳过。
  - 手掌多边形不要用凸包（会吃进爪根描边残渣变毛边），用「切割线 y 处实测左右宽 + 底尖中点」直接构梯形。
- **前臂**：凸包会填掉护甲板上缘与上臂之间的凹陷（几百像素小三角，待机被上臂盖住，可接受）。
- **腿脚一体件**：踝部黑线 = 腿与脚两个多边形各自的描边叠合，与原图一致，不要试图去掉。
- **头**：外轮廓用拟合圆/椭圆重绘，内部整块贴原图（侵蚀 18px 以内），五官零失真。

## 7. pivots.json 规范

- 坐标系：原点左上、X 右 Y 下、母图画布像素；`canvas` 字段记录画布尺寸。
- 每件 `pivot` = 关节中心：头→颈、上臂→肩、前臂→肘、手掌→腕、腿脚→髋、torso→腹部中心（树根）。
- `root` = 两脚脚底中央的底边中点（整体定位）。
- `draw_order_back_to_front`：torso → 腿 → 前臂 → 上臂 → 爪 → head（几何熊正面验证值）。
- 父子：torso→head；torso→upper_arm→forearm→claw；torso→leg_foot。
- 左右镜像：`pivot.x' = 画布宽 - pivot.x`（`_r` = 角色自身右侧 = 屏幕左侧，写在文件 note 里）。

## 8. 验收清单（每次拆完必出）

1. `assembled_preview.png`：拼回 vs 原图并排。指标用 **alpha 感知 diff**（原图透明像素 RGB 非零，直接比 RGB 会全图误报）；目标 alpha 差 < 0.5% 且差异只集中在描边线。
2. `parts_preview.png`：分件网格展示——逐件检查：护甲不串进上臂、肚皮不串进腿、爪尖不串进腿、边缘无碎点散线。
3. `articulation_preview.png`：抬臂 90°＋弯肘 90°＋转腕 45°——关节无透明裂缝、无悬浮碎片、无不合理黑边。旋转用正向运动学：先绕肩转，再绕**旋转后的**肘点转，依此类推。
4. 用户验货重点 historically：边缘齐平度、串件、爪根封口——先自查这三项再交付。

## 9. 工程规范

- 输出目录：`geometric/<角色>/parts/<方向>/`；10 件 + pivots.json + 3 检查图 + README.md（写约定和已知瑕疵）。
- 旧版归档：`<方向>_vN_draft/` + `OBSOLETE.txt`，不删除。
- 改完同步根 `README.md`（§2 目录树、§7/§8 状态）和 `art_manifest.json`（加 group）。
- 脚本即配方：部件要改就改脚本重跑，不要手改单个 PNG（下次重建会覆盖）。
- 扩展到其他方向：02~08 画布是 1024×1024 且比例有 7%~34% 漂移（根 README §7 P0-1），不能直接套正面坐标，需重新做连通域分析。

## 10. 生成素材阶段的配套经验（拆件之前的事）

- ImageGen `background:"transparent"` 不生效，必须后处理去背；
- 并行生成同秒文件名互相覆盖 → 串行生成、出图即改名；
- 图生图做朝向旋转：`input_fidelity=low` + "转盘旋转 X 度"语言才转得动；
- 整图生成序列帧帧序不可控 → 逐帧生成 + `_compose_attack_sheet.py` 拼版（统一缩放+脚底基线对齐）；
- 被删的生成图可从 `C:\Users\hyc\.workbuddy\blobs\` 按修改时间找回。
