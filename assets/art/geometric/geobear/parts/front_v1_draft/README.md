## 关键约定

- **左右按角色自身**：`_r` = 角色右侧 = **屏幕左侧**。
- 所有部件画布 = 原图 **1254×1254**，部件在原位，不居中、不紧裁、不缩放 —— 直接叠放即还原。
- 坐标系：原点左上，X 右 Y 下（像素）。
- 绘制顺序（后→前）：`torso → leg_foot_r/l → forearm_r/l → upper_arm_r/l → claw_r/l → head`。
- 父子关系：`torso → head`；`torso → upper_arm → forearm → claw`；`torso → leg_foot`。
- 隐藏补画全部是无描边平涂青蓝；外露轮廓保留原粗黑描边。相接处两层描边同为 `#06070B`，叠合不可见。
- Godot 里建议 `texture_filter = Nearest`（或 Linear＋整数倍缩放），粗描边不发虚。

## 已知瑕疵（建议人工修一笔的地方）

1. **前臂/上臂/爪的隐藏补画边缘是规则几何形**（圆/椭圆），旋转到极限角度时边缘略显"圆墩墩"，属可接受范围；如需更自然可在补画区手扫两笔。
2. **leg_foot 顶部髋线外侧有极少碎像素**（待机下被躯干/前臂完全盖住，不影响拼装与常规摆动）；大幅侧抬腿时可能露出，届时手工擦掉即可。
3. **抬臂 90°＋弯肘 90° 时肘部后侧有 1~2 条细小黑线**（原图肘缝描边随前臂旋转所致），见 `articulation_preview.png`，剪纸动画常规容忍范围内。
4. 拆分只做了**正面**；其他七个方向如需拆件，改脚本 `_split_geobear_front.py` 的区域坐标后另存（注意 02~08 画布是 1024×1024、比例有漂移，见根 README §7 P0-1）。
