## 约定

- `_r` = 角色右侧 = **屏幕左侧**。
- 全部部件 1254×1254 与原图同画布、原位，直接叠放即还原。
- 坐标：原点左上，X 右 Y 下。
- 绘制顺序（后→前）：`torso → leg_foot_r/l → forearm_r/l → upper_arm_r/l → claw_r/l → head`。
- 父子：`torso → head`；`torso → upper_arm → forearm → claw`；`torso → leg_foot`。
- 描边宽 13px（与原图一致），同色 `#06070B`，接缝处叠合不可见。
- 隐藏补画为无描边平涂青蓝（圆形/椭圆，旋转不露直角）。
- Godot 建议 `texture_filter = Linear`＋整数倍缩放（v2 边缘带 AA，Linear 下更干净）。

## 已知瑕疵

1. 前臂轮廓用凸包拟合，护甲板上缘与上臂之间的凹陷被填成青蓝（待机大部分被上臂盖住，露出的小三角约几百像素）。
2. 极限弯肘时肘部内侧有轻微黑线叠压（两层描边不完全重合），见 articulation_preview，剪纸动画常规容忍范围。
3. 肘/髋的隐藏补画（圆形/椭圆填肉）在部件单看时会有小圆包，拼装后被邻近部件盖住；抬臂/弯肘时露出为纯色关节球，属预期。
4. 拆分仅正面；其余方向需改脚本区域坐标另跑（02~08 画布 1024×1024，注意比例漂移）。

## 设计说明（v2.1 用户修订）

- **爪根不封口**：三根三角爪只描两侧边，顶部（爪根）不画封闭黑线，让爪子从掌部自然长出（2026-10-22 用户明确要求）。
- **手掌**：掌部 = 前臂底尖多边形，顶部切边不描线（避免腕部多出一条横线），侧/底边与前臂轮廓重合。
- 前臂、上臂、腿脚的外轮廓描边全部为程序化重绘（不粘贴原图描边），保证边缘齐平无碎线。
