# Geocat（几何布偶猫）生成提示词

风格基准则：与 geobear 同一套几何扁平矢量语言（粗近黑描边 / 纯色块 / 无阴影渐变）。
原型：双色布偶猫（灰蓝面罩 + 白色流星斑 + 蓝眼 + 粉鼻 + 奶油白蓬松身体）。

## v2 中文提示词（当前正式版）

```
为2D动作游戏设计一只原创几何布偶猫怪物，单个角色，全身正面，固定平视镜头，四足稳稳站立。风格与同系列的「几何熊」完全一致：敦实、沉重、笨拙的怪物感，圆润但简洁可爱。
角色完全由简单的圆形、矩形、梯形、三角形和少量多边形组成，每个体块都要又宽又厚：
圆形的大脑袋，两只直立的三角形耳朵，耳朵粗大；
头部两侧各一块浅色多边形，表现蓬松的腮毛；
上宽下窄的宽大梯形身体，肩部明显比腰部宽，躯干厚实饱满；
胸腹只有一块更浅的米白色多边形；
四条腿是又短又粗的矩形，粗壮敦实，明显比geobear更胖更圆；
宽大的梯形脚掌，四只脚掌全部清晰可见；
身后一条粗大的多边形长尾巴向上弯曲竖起，尾巴根部很粗，尾尖为深色多边形。
整体敦实、沉重，像一团会走路的长毛团子，简洁可爱中带一点小凶。
大而圆的明亮蓝色眼睛，小小的粉色三角形鼻子，简单闭合嘴巴。
布偶猫标志性配色：面部深灰蓝色面罩覆盖眼周和耳根，一道白色流星斑从额头中央一直延伸到鼻梁，覆盖口鼻和下巴；耳朵与尾巴尖同为深灰蓝色；身体为奶油白/米白色。
所有外轮廓和内部形状边界使用统一、非常粗的近黑色描边，线条粗重有力。
大面积纯色色块，不使用任何阴影。
平面矢量插画感，轮廓鲜明，缩小后仍能辨认。
造型必须简单，适合初学者重画和拆分关节动画。
角色居中，四周留白，浅米白色纯色背景。
不要毛发细节、肌肉刻画、复杂花纹、装饰、渐变、纹理、立体渲染或密集低多边形切面。
不要额外武器、服装、动作特效、文字、水印或其他角色。
```

| 蓝色大圆眼 | 亮蓝圆眼 + 白色高光点 |
| 粉色小鼻 | 粉色小三角 + 一条短嘴线 |

| 深色尾尖、粗大尾巴 | 粗根多边形尾上翘，尾尖深色 |

## v1 → v2 的改动

1. 腿：从细长 → 又短又粗的矩形，脚掌加大，四脚全露。
2. 身体：从瘦方块 → 上宽下窄、肩部明显更宽的厚实梯形。
3. 气质：从"站着的家猫" → "会走路的长毛团子"，往 geobear 的敦实怪物感靠。
4. 蓬松感：从写实毛发 → 全部由块面多边形表达。
