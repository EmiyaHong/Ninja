# Geocat 正面拆件（剪纸式关节动画 · 7 件）

母图：`../../geocat_stand_01_front.png`（1024×1024 RGBA）。
所有部件与母图**同画布、同位置**，直接叠放即还原；不缩放、不居中、不紧裁切。

## 为什么是 7 件而不是熊的 10 件

四足猫没有手臂/护甲/三爪，熊方案的「上臂→前臂→手掌爪」链对应猫的四条腿
（腿脚暂不细分，与熊的 leg_foot 同级处理）。多出来的是尾巴。
左右按**角色自身**定义：正面图里角色右侧 = 屏幕左侧。

## 隐藏区补画（旋转后不露缝）

- **头**：颈桩米白椭圆（(512,575) 95×45），无描边，压在躯干胸腹白色块上，转头时填颈部。
- **躯干**：头顶后补奶油椭圆（(460,490) 185×65，藏在头后）；底部延伸块 + 底边描边
  （y=800，仅腿列范围内）藏在四腿之后——**腿抬 90° 后躯干底边仍完整**。
- **腿**：髋包奶油椭圆（腿根 46×32），无描边。
- **尾**：尾根奶油椭圆（(670,685) 50×45），藏在躯干右后。

## 接缝线的归属（避免双重黑边/旋转黑茬）

- 头身接缝：两侧黑色弧线是**头的轮廓**（头在最前）；中央白色口鼻-胸腹连续区
  无线，开边切割（y≈562），拼接后无线。
- 腿根分隔线：**平段**（y≈770，各腿正上方）归**腿**——腿顶描边随腿走；
  **V 形斜线**（腿缝间，y<764）归**躯干**——腿转动时腿缝的线不动。
  躯干上对应位置的原始黑线已剔除，不会双线。
- 尾根藏在躯干后面，躯干右缘线即分隔线。

## 仍需修正 / 后续

- 隐藏补画包在**中性位**与原图零色差（直接拷贝原图像素）；大幅旋转后露出的
  补画区域是原图相应位置的拷贝，颜色自然但纹理不动。
- 腿脚目前是一整件；如需踝关节（脚掌单独转），按同样方法从 y≈845 白色脚掌线处再拆。
- 尾巴只在角色左后侧（正面看在屏幕右侧），其余七个方向的拆件需按各自方向重做。
- 生成脚本：`_tools/_split_geocat_front.py`，改参数重跑即可（会覆盖本目录 PNG）。
  质检方法：拼装后与原图做 alpha/RGB 逐像素 diff（缺失/多出/色差三项）+ 孤儿像素救援
  （主连通过滤会把插在别家区域的碎片丢掉，需按最近部件收回）。
